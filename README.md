# WebП-5-сем — Лабораторная работа №1

Статический сайт компании «Зелёный Берег» на HTML5 / CSS3 / JavaScript.

## Структура

```
├── index.html      # Главная
├── about.html      # О нас
├── contacts.html   # Контакты (+ JS-валидация формы)
├── services.html   # Услуги
├── css/
│   ├── style.css
│   └── responsive.css
├── js/
│   └── script.js   # бургер-меню + валидация формы
└── images/
```

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
npx serve .
```
