# ЛР4 — клиентская часть (React + Vite)

Эволюция SPA из ЛР3: добавлены регистрация/вход, калькулятор стоимости, корзина,
оформление заявок, личный кабинет, трекинг статуса и админ-панель.
Все данные идут через REST API бэкенда (`../backend`, FastAPI).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173, /api проксируется на 127.0.0.1:8000
```

Перед запуском поднимите бэкенд — см. `../README.md`.
